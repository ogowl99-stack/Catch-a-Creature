# Progress Media

This folder tracks short development captures intended for truthful "day N of making a Roblox game" posts.

## Capture rule

Capture only visually meaningful milestones:

- World or lighting transformations
- First working planting, growth, harvest, and selling loop
- Major UI reveals and responsive layouts
- First creature arrival, behavior, and capture presentation
- Before/after comparisons for production assets or effects

Do not record routine source setup, documentation edits, repetitive debugging, or fake progress. A clip may be labeled `Verified`, `Simulated`, or `Requires Roblox Studio testing`; it must never imply that staged footage is finished gameplay.

## Recommended raw format

- Vertical target: 9:16 at 1080x1920 when the recorder supports it
- Raw duration: 8-20 seconds per moment
- Keep a clean gameplay/viewpoint version without captions so editing remains flexible
- Capture one establishing shot and one close interaction when the change justifies both
- File naming: `day-###_short-feature-description_raw.mp4`

The current Studio MCP connection provides still captures, not native video recording. Until a dedicated recorder is configured, stills must be logged as stills rather than called clips. Real video capture should begin with the first visually meaningful Phase 3A gameplay milestone.

## Manifest

Every retained capture belongs in `clips.json` with its date, feature, truth label, capture method, duration, and notes about what is and is not shown.
